# Linux Fundamentals Part 1

## Objective
Learn basic Linux commands for file navigation and file handling.

## Commands Learned
- pwd
- ls
- cd
- cat
- grep

## Procedure
1. Used `pwd` to check the current directory.
2. Used `ls` to list files and folders.
3. Navigated into the required folder using `cd`.
4. Listed the contents again using `ls`.
5. Read the file using `cat`.
6. Used `grep` to search for the flag in `access.log`.

## Challenges Faced
- Tried to use `cat` on a directory.
- Received "No such file or directory" because I was in the wrong directory.
- Learned to navigate into the correct folder before reading files.

## Key Learnings
- Difference between files and directories.
- Basic Linux navigation.
- Searching text using `grep`.
